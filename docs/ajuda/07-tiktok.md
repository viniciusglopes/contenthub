# TikTok

## O que funciona hoje

- Cadastrar a conta do TikTok no projeto (Configurações, Redes Sociais), só como registro.
- Planejar posts para o TikTok no calendário e baixar o vídeo para postar à mão.

## Ainda não disponível

> **Ainda não disponível:** ler números do TikTok e publicar no TikTok pelo ContentHub.

O motivo: a API oficial do TikTok para ler perfil e vídeos (Display API) exige conta de desenvolvedor e aprovação do app. Para publicar (Content Posting API), o app precisa de aprovação e auditoria; antes da auditoria os posts só podem sair como **privados** e para poucas contas por dia.

Fontes oficiais: [Display API](https://developers.tiktok.com/doc/display-api-overview), [Content Posting API](https://developers.tiktok.com/doc/content-posting-api-get-started) e [regras de compartilhamento](https://developers.tiktok.com/doc/content-sharing-guidelines)
